What this page shows

It feeds the player's brain (core.js) invented samples, 250 ms apart, the way the page does while a video plays, and prints what the core decides: when it hops to the other server, how long the picture is stopped, and why a failure is called network, format or playback. A run takes no real time.

Every case runs twice: with the buffer watch (the new trigger: hop when the buffered end has stopped growing) and without it (only the older triggers, which wait for the picture to stop). The pause a viewer sees in life also includes the new connection's own start (measured 0.1 to 3.5 s on the Archive); here you set it.

Each card ends in "as designed" or "NOT as designed" against DESIGN.md ("Why it failed: the cause table" and "The buffer watch"). For a real video and a real stall, use the main lab and its soak test.
