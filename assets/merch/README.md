# VOIDtv merch pack

Everything here is ours to print: the mark, the wordmark set in Unbounded, the tagline, and QR codes
that point at tracked short links. Nothing from any show is in here (posters and stills belong to the
studios and cannot go on merch).

## Files

- `design-front-on-dark.png`, `design-front-on-light.png` (3000 x 3000, transparent): mark + wordmark + tagline, for dark garments and for light ones.
- `design-back-on-dark.png`, `design-back-on-light.png` (3000 x 3000, transparent): QR code + wordmark + "free · no ads · no accounts". The QR points at `voidtv.net/q/tee-back`.
- `wordmark-light-6000.png`, `wordmark-dark-6000.png` (6000 x 1400, transparent): the wordmark alone, for hats, sleeves, stickers.
- `tagline-light-4000.png`, `tagline-dark-4000.png` (4000 x 1200, transparent): "before AI slop, there was human creativity".
- `mark-full-colour-904.png`, `mark-full-colour-1200-canvas.png`: the round V/T mark at its native resolution (904 px) and on a 1200 px canvas with margin. For embroidery or anything larger than about 4 inches, have the printer vectorise this file or ask for the vector version.
- `mark-one-colour-white-904.png`, `mark-one-colour-black-904.png`: single-ink silhouettes for screen printing.
- `qr-*.svg` (vector, prints at any size) and `qr-*-2000.png`: one code per placement, black and white versions:
  `qr-voidtv` = tee-back · `qr-hoodie` · `qr-sticker` · `qr-card` · `qr-cash` (points at the CASH page).

## The QR codes are tracked

Each code is a short link, `https://voidtv.net/q/<code>`. A scan is counted (country, region, city,
device, browser) and forwarded to the target. HQ > QR codes shows scans per code, lets you add codes
for new placements, change a target later without reprinting, and download the SVG or PNG.
Keep a code per placement (front, back, sticker, card) so you learn which one people actually scan.

## Printing notes

- Transparent PNGs: the designs float on the garment colour. Use the "on-dark" files for black, navy
  and charcoal; "on-light" for white, cream and heather grey.
- Wordmark colours: cream #e8e8ee, VOIDtv cyan #5fd4ff, gold #f2a93b. Background #07080c if you need the brand black.
- Fonts: the wordmark is Unbounded (open licence, in `assets/brand/fonts/`) so a printer can set new text in it.
- QR: keep the quiet zone (the clear margin in the file), print at least 1 inch square, never stretch it, and
  test a scan from the proof before a run.
