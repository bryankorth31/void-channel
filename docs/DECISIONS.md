# voidtv.net: the decisions to keep

Every rule and decision Bryan (B) has stated for voidtv.net and its tools, in one list: what was decided, his own words, when, where it
lives in the code, the test that fails if it breaks, and whether the code still does it. Built by the full build audit of 25 Oct 2026
(phase 2) from his messages in every VoidTV chat, the project memory, the plans, the commit messages and the docs.

**Check this list before every change.** Read the section you are about to touch. If a change would go against a line here, stop and ask
B first. When B changes his mind, change the line here in the same commit: write the new decision, his words and the date, and move the
old one to section 14 (retired). A new decision gets a row and, where code can hold it, a test.

B's words: "I just don't want changes happen from drift with adding new things." (25 Oct 2026)

The tests: most rows point at the test file that already holds them. Rows that had no test are held by `tests/decisions.test.js`, one
test per row, named by the row's id. A test marked todo there is a known drift: it is reported as todo and does not fail the suite until
the fix lands, and the fix takes the todo flag off and changes the row to HOLDS in the same commit.

Checked: 25 Oct 2026 against the live commit 7d3326207 (tag audit-base-2026-10-25b); rows G6, P11 and M18 moved to HOLDS on 26 Oct (audit batch A). Quotes are as B typed them (shortened, never
reworded). The private sources (chat archive, audit ledgers) stay on B's PC; this file names them only.
