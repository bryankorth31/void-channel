One engine per arcade machine family, named after its MAME source file, served from play/engine/mame/:
williams: SOURCES=src/mame/williams/williams.cpp (Joust, Defender, Robotron, Stargate and the other Williams machines in that file)

Build command, run in the MAME folder from Git Bash with emsdk active (EMSCRIPTEN pointing at emsdk/upstream/emscripten):
make -j14 BUILDDIR=build-os OPTIMIZE=s SUBTARGET=<name> SOURCES=<driver .cpp files> NO_USE_PORTAUDIO=1 NO_USE_MIDI=1 \
  PYTHON_EXECUTABLE=<python 3> CLANG_VERSION=24.0.0 CC=$EMSCRIPTEN/emcc CXX=$EMSCRIPTEN/em++ AR=$EMSCRIPTEN/emar \
  NOWERROR=1 REGENIE=1 PRECOMPILE=0 "ARCHOPTS_CXX=-include cstdlib -include cmath -include vector"
Why the extra settings: CLANG_VERSION because MAME's makefile cannot read Emscripten's version on Windows; NOWERROR because
this compiler is newer than MAME's code and warns more; the three -include flags supply standard headers newer libc++ no
longer pulls in by itself; PRECOMPILE=0 because a precompiled header must be the first include. None changes MAME's code.
It writes <name>.js and <name>.wasm in the MAME folder; the notice line at the top of each served .js is added by hand
when copying it into play/engine/mame/.
